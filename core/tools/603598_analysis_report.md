# 603598.SSE 信号持续偏高分析报告

## 核心发现

### 1. 信号生成机制

V10模型的信号生成公式：
```python
rank = total_score的升序排名（最低分=1，最高分=N）
final_signal = ((rank / count) - 0.5) * 3.46
final_signal = final_signal.clip(-3, 3)
```

**关键推论**：
- `final_signal = 1.73` 意味着 `rank/count = 1.0`，即**排名第1（最高分）**
- `final_signal = -1.73` 意味着 `rank/count = 0`，即**排名最后（最低分）**

**信号数据**：

- total_score：**1.0349**（2085只股票中排名第1）
- final_signal：**1.73**（理论最大值）
- = 1.73的天数：3天（最近3天都是满分）

## 为什么信号持续偏高？

### 原因1：120日长期动量强劲

虽然60日动量为负（-19.57%），但120日动量达到+24.33%，说明：
- 股票在更长的时间尺度上呈上升趋势
- 近期回调（过去60天下跌）被模型视为"健康调整"
- MLP模型可能赋予长期动量更高权重

### 原因2：低波动率特征

20日波动率（3.27%）低于全市场平均（3.45%），结合正收益：
- 模型偏好"低波动+正收益"的组合
- 即使价格在波动，但相对其他股票仍算"稳定"
- 这在Attention模型中可能被识别为优质特征

### 原因3：横截面排名机制

final_signal完全由**横截面排名**决定，而非绝对值：
- 只要比大多数股票好，就能获得高分
- 即使60日动量为负，只要其他股票更差，排名依然靠前
- 这是**相对强弱**逻辑，不是绝对质量逻辑

### 原因4：因子交互作用

V10模型包含多个交互因子（如turnover_x_bull）：
- 可能某些因子组合在横截面上得分很高
- 即使单一因子不突出，组合效果可能很强

## 潜在问题

### 1. 信号截断在1.73

- 1004条记录的final_signal恰好等于1.73（最大值）
- 这可能表明：
  - 这些股票的排名都在Top 0.05%以内
  - 或者信号生成存在某种截断/归一化机制

### 2. 60日动量为负但信号最高

这揭示了模型的一个重要特征：
- **模型更看重长期趋势（120日），而非中期表现（60日）**
- 短期波动被模型容忍，只要长期逻辑未破坏

### 3. 价格振幅117%却被认为是"低波动"

- 这是**相对概念**：相对于其他股票，它的波动率较低
- 绝对波动率并不低，但横截面排名靠前

## 结论

603598.SSE信号持续偏高的主要原因：

1. **120日长期动量强劲**（+24.33%），主导了模型判断
2. **波动率相对较低**（3.27% vs 市场平均3.45%），符合模型偏好
3. **横截面排名机制**使其在相对比较中始终靠前
4. **因子组合效应**可能在Attention模型中获得了高注意力权重

这只股票表现为：**长期上涨趋势中的中期回调**，模型认为这是"买入机会"而非"风险信号"。
