# V15 双股票池单模型 - 风格 Regime 因子迭代

> 创建日期：2026-05-19
> 基线：V14 单池（CSI 2000 Sharpe 1.42 / CSI 1000 Sharpe 1.19）
> 目标：用一个模型同时覆盖 CSI 1000 + CSI 2000，让模型自动识别风格切换
> 状态：**V15.1 成功** - Sharpe 1.51 / 年化 89.7% / MaxDD -23.5%（超越两个单池）

---

## 一、问题背景

V14 在不同股票池上表现差异巨大（依赖于风格周期）：

| 年份 | V14 CSI 2000 | V14 CSI 1000 |
|:---|:---|:---|
| 2022 | +13.5% | +73.9% |
| 2023 | +37.4% | +15.3% |
| 2024 | +74.9% | +15.6% |
| 2025 | +39.5% | +59.0% |
| 2026 | -12.6% | +19.0% |

CSI 2000 在 2024 年大胜（+74.9%），但 2026 年大跌（-12.6%）。
CSI 1000 在 2022 年最强（+73.9%），但 2023/2024 表现一般。

**用户诉求**：能否训练一个模型同时覆盖两个股票池，让模型从因子中自动识别风格切换。

---

## 二、迭代过程

### 2.1 V15-初版：5 个 regime 因子 + 全截面排名（失败）

加入 5 个 style regime 特征：
- `pool_size_rank`, `style_regime`, `style_regime_60`, `mom_x_regime_align`, `mom_x_regime_contrarian`

**结果**：2024 年 -15.5%，风格轮动信号滞后被甩。

### 2.2 V15 Size-Neutral 标签 + Size 相对因子（彻底失败）

思路：剥离 size premium，让模型只学"同市值层内的纯 alpha"。

```python
excess_ret_10_neutral = cs_neutralize(excess_ret_10, size_ln)
features["label"] = cs_rank(excess_ret_10_neutral)
```

**结果**：Sharpe 0.31 / MaxDD -36.7% / 年化 7.9%（基本与基准齐平）。

**失败机理**：在混合池里，size premium 是主要 alpha 来源之一，强行剥离等于把模型的 timing 信号一并去掉。

### 2.3 训练参数干扰排查

实验中曾把 `n_epochs` 1000→400, `early_stop_rounds` 40→20。
回测显示 V14 CSI 2000 从 Sharpe 1.42 → 1.22, MaxDD -20.4% → -40.5%。
**结论**：模型容量不能缩水，回退到 n_epochs=1000 / early_stop=40。

### 2.4 V15.0：5 个 regime 因子 + V14 标签（部分成功）

回退 size-neutral 标签，恢复 V14 全截面 beta-neutral 10 日标签，保留 5 个 regime 因子。

**结果**：Sharpe 1.33 / 收益回撤比 6.52 / 每年正收益，**但每年都不如单池最优年份**。

**机理**：5 个 regime 信号太弱，模型只学到了风格的"平均"，没有真正的 timing。

### 2.5 V15.1：升级 regime 因子到 13 个（**成功**）

新增 8 个 timing 维度：

| 因子 | 含义 |
|:---|:---|
| `style_regime_5/20/60` | 多窗口大/小盘动量差 |
| `style_regime_change` | 短-长期差，捕捉风格切换加速度 |
| `style_regime_strength` | 风格分化强度（无方向） |
| `vol_regime` | 大/小盘 20d 波动差 |
| `turnover_regime` | 大/小盘换手率差 |
| `amihud_regime` | 大/小盘流动性差 |
| `pool_size_x_regime` | **个股市值排名 × 风格方向（核心 timing 交互）** |
| `pool_size_x_regime_change` | 个股市值排名 × 风格切换方向（早期入场） |

**核心创新**：`pool_size_x_regime` 让模型**直接学到"我所在的池现在顺不顺风"**。

```python
regime_direction = torch.tanh(style_regime_20.expand_as(C) * 10.0)
features["pool_size_x_regime"] = features["pool_size_rank"] * regime_direction
```

## 四、关键经验

1. **混池单模型可行**，前提是 timing 信号要足够丰富。
2. **不要剥离 size premium**：在混合池里 size premium 是主要 alpha 来源。
3. **交互特征 `pool_size × regime` 是 timing 关键**：让模型直接看到"我顺不顺风"，而不是猜。
4. **多维度 regime（动量+波动+换手+流动性）**优于单一动量维度的 regime。
5. **训练参数（n_epochs / early_stop）不能轻易缩水**：模型容量决定上限。

---

## 五、新沉淀知识

- 混合股票池单模型方案在 A 股可行，但需要 13+ regime 信号 + 强 timing 交互
- "在哪个池+池现在顺不顺风" 是关键的二阶因子，单一 regime 因子无法替代
- size-neutral 标签在混池下等于损失主要 alpha 信号，与单池逻辑相反
