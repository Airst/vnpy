# V18 失败记录：基于信号 + 持仓盈亏的动态仓位调节（全路线放弃）

## 实验背景

V15.3 基线（Sharpe 1.74 / 年化 113.9% / MaxDD -21.1%）锁定后，V16/V17 因子层探索失败回退。
本轮迭代不再触碰因子层，转向**策略执行层**：在 MultiFactor 等权选股的基础上，叠加"信号强度 + 持仓盈亏"动态仓位调节，期望通过执行层精细化提升 Sharpe。

## 设计方案

```
TargetWeight(s) = BaseWeight × SignalScale(s) × PnLScale(s)
   sum(TargetWeight) ≤ 1.0
```

四个独立机制，按消融实验拆分迭代：

| 机制 | 描述 | 触发条件 |
|---|---|---|
| **SignalScale** (V18.1) | 入场分档加权 | Top1=1.5×, Top2=1.2×, 其余=1.0× |
| **loss_cut** (V18.2 子) | 浮亏早期减半仓 | -5% < pnl < -3% (硬止损前) |
| **signal_fade** (V18.2 子) | 信号衰减分档减仓 | buy_threshold ≤ score < sell_threshold |
| **pyramid** (V18.3) | 浮盈金字塔加仓 | pnl > +20% 且 score ≥ buy_threshold |
| **holding_decay** (V18.4 未实施) | 持仓天数衰减 | ≥20天且pnl<+3% 减半 / ≥40天清仓 |

## 实施环境

- **基线信号**：复用 `ashare_mlp_signal_v15` parquet（无需重训模型）
- **回测期**：2022-01-01 → 2026-05-22（1059 个交易日）
- **基线指标**：Sharpe **1.27** / 年化 60.75% / MaxDD -26.66% / 收益回撤比 5.33
  > 注：本次基线 Sharpe 1.27 比 AGENTS.md 记录的 V15.3 (Sharpe 1.74) 低，是数据延伸到 2026-05 后的退化。本实验内部对比一致。

  - 新建 `core/position_scaler.py`（纯函数式仓位权重）
  - 改造 `core/strategies/multifactor_strategy.py`（目标权重差分 + 部分减仓 + 金字塔加仓）
  - `training.py` 加 `-bo/--backtest-only` 开关（保留，后续可复用）

## 完整失败矩阵

| 版本 | 启用机制 | Sharpe | 总收益 | 年化 | MaxDD | 触发次数 |
|---|---|---:|---:|---:|---:|---:|
| **Baseline V15.3** | (无) | **1.27** | 269.38% | 61.05% | -26.66% | - |
| V18.1 | SignalScale | 0.96 | 163.13% | 36.97% | -30.73% | - |
| V18.2 | loss_cut + signal_fade | 1.05 | 300.10% | 45.35% | -26.78% | - |
| V18.2a | 仅 signal_fade | 1.13 | 318.17% | 49.44% | -27.03% | - |
| V18.2b | 仅 loss_cut | 1.02 | 177.42% | 40.21% | -24.65% | - |
| V18.3 | 仅 pyramid (默认互斥) | 1.27 | 269.38% | 61.05% | -26.66% | **0 次** |

**所有变体 Sharpe 全部下降，本轮迭代整体失败。**

## 失败诊断

### 1. SignalScale 失败 — A 股牛市轮动反例

V18.1 整体 Sharpe 1.27 → 0.96，年化 -24%。

**90 天分段定位**（2024-07-08 → 2024-10-08 牛市）：
- Baseline +56.53%
- V18.1 +13.48%（**集中押注 Top1 损失了 43%**）

**根因**：
- final_signal 是 **rank-based 归一化**信号（`mlp_signals.py:466-476`），Top1 ≈ 1.73, Top5 ≈ 1.5，差异 < 0.3
- GP 因子集已饱和（AGENTS.md 4.2-20），头部排名 noisy，Top1 不显著优于 Top5
- A 股牛市是板块快速轮动，**分散持仓比集中持仓捕获机会更多**

### 2. loss_cut 失败 — 减半反弹双重摩擦

V18.2b（仅 loss_cut）Sharpe 1.27 → 1.02，**交易笔数 1329 vs 基线 1177（+13%）**。

**根因**：
- -3%~-5% 减半仓后，剩余半仓继续下跌触发硬止损 → 同一标的两次卖出在不同价位
- 或减半后市场反弹，被动错过反弹收益（24Q2: -1.76% → -13.13%）
- "Cut losses short" 在 A 股日频截面框架下产生**双重摩擦成本**

### 3. signal_fade 失败 — std 升高超过 alpha 改善

V18.2a（仅 signal_fade）Sharpe 1.27 → 1.13，**总收益反而 +48%**（318% vs 269%）。

**根因**：
- signal_fade 在弱信号区间渐进减仓，**改善了 24Q4 / 25Q1 非牛市回撤**
- 但 24Q3 牛市因 score 短暂跌破 sell_threshold 减半后再涨上来时仓位不足，**少赚 9.6%**
- daily return std 从 1.47% 升到 1.50%，**Sharpe 分母恶化超过分子**

### 4. pyramid 失败 — 与 sell_threshold 结构性互斥

V18.3（仅 pyramid，默认逻辑）**0 次触发**，与 baseline 完全等同（Sharpe 1.27 同值）。

**根因**：
- 持仓股要 pnl > 20% 必须持续上涨多日
- A 股普涨时，该股 score 的相对排名往往下滑（其他股也涨）
- 一旦 score < sell_threshold(1.54)，立即被 V17 原逻辑全部清仓
- → **永远等不到 pyramid 触发条件**（结构性互斥，非参数问题）

### 5. 利润仓豁免（V18.3b）失败 — 副作用大于收益

为打破 pyramid 互斥，给"pnl > 10% 且 score ≥ buy_threshold"的盈利仓豁免 sell_threshold 清仓：
- pyramid 触发上升到 2 次（4 年回测期）
- 但 Sharpe 1.17 < baseline 1.27，**MaxDD 恶化到 -29.27%**

**根因**：
- 24Q3 牛市少赚 17.7%（盈利仓延迟卖出，新仓位无法买入，错失轮动）
- 24Q1 非牛市 -18.20% vs baseline -13.52%（豁免仓 pnl 从 +10% 跌到 -5% 触发硬止损但浮盈已丢）
- **豁免规则改变了核心退出逻辑，副作用远大于 pyramid 加仓收益**

## 核心认知（沉淀到 AGENTS.md 第四章）

V18 整轮迭代揭示了 A 股截面选股 + 日频调仓框架下的关键认知：

### 21. 执行层的复杂仓位调节是 Sharpe 杀手

四类机制全部失败，证明在以下框架约束下：
- 5 个持仓的小组合
- 日频调仓 + T+1
- 整手 100 股 + 跌停滑点
- 排名归一化信号

**简单的"等权 + score 阈值清仓"已是接近最优的执行规则**。复杂化引入：
- 减半仓的双重摩擦成本
- 信号分档损害板块轮动捕获
- 盈利仓豁免延迟卖出错失轮动机会

### 22. 信号强度分档失败的 A 股特殊性

A 股牛市以板块快速轮动为特征，**集中持仓损害收益捕获**，与美股价值股长期持有逻辑不同。
学术上的 IC × signal_strength 加权（Markowitz 改良）在 A 股日频截面框架下不成立。

### 23. pyramid 加仓与排名退出存在结构性互斥

任何"基于持仓盈亏的加仓机制"必须先解决与"基于信号排名的退出机制"的优先级冲突。
若不改 sell_threshold 退出逻辑，pyramid 永远 0 次触发；若改了，副作用一定大于加仓收益（V18.3b 实证）。
**该方向暂停**。

### 24. 减半仓在 A 股日频框架下产生双重摩擦

"Cut losses short" 经典法则在 A 股 T+1 + 5 持仓 + 整手 100 约束下：
- 减半后反弹错失收益（亏损扩大）
- 减半后继续跌触发硬止损（两次卖在不同价位）
- 交易笔数飙升 13%~28%，手续费 + 滑点累计成本超过 alpha 改善

**该方向暂停**。
